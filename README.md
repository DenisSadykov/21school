# Исповедь — пять историй

Откройте `index.html` в браузере. Презентация работает локально, без подключения к интернету. Листайте стрелками клавиатуры, пробелом, колесом мыши или кнопками на экране. Кнопка «Карта» открывает переходы между историями.

Порядок историй:

| Автор | Содержательные слайды исходника | Экранов в этой версии |
| --- | --- | ---: |
| Лёша | 2–13 | 12 |
| Аня | 2–12 | 11 |
| Катя | 2–18 | 17 |
| Римма | 1–7 | 7 |
| Никита | 2–10 | 9 |

Перед историями добавлен один общий вступительный экран. Фото, скриншоты и их последовательность перенесены из авторских презентаций; намеренные наложения в коллажах Кати сохранены. Общий фирменный фон и значки PowerPoint заменены текущим оформлением «Исповеди».

На слайде Лёши с котом убрана надпись: в показе используется `assets/lesha-s10-2-clean.png`, исходное фото сохранено как `assets/lesha-s10-2.png`.

На первом слайде Риммы используется `assets/rimma-image12-with-dog.png` — версия группового фото с добавленной собакой. Неизменённый оригинал сохранён как `assets/rimma-image12.jpg`.

Та же собака добавлена ещё на девять фотографий в историях Лёши, Ани, Кати, Риммы и Никиты. В показе используются отдельные файлы с суффиксом `-with-dog.png`; исходные фотографии оставлены без изменений.

Катин исходный титульный слайд «Исповедь» не дублируется; финальный экран «Вопросы?» удалён по запросу. Название папки оставлено прежним, чтобы уже открытая локальная ссылка на презентацию продолжала работать.
