# Исповедь — пять историй

Откройте `index.html` в браузере. Презентация работает локально, без интернета.

Первый экран сразу показывает пять спикеров. Отдельного титульного слайда нет.

Управление: стрелки вправо/влево, пробел, колёсико мыши, свайп или кнопки внизу. Кнопка «Карта» открывает главы.

Порядок: Полина → Аня → Римма → Таня → Денис. В общей версии 50 экранов. Содержательные слайды Полины (6), Ани (11), Риммы (5) и Тани (16) идут в порядке их исходных презентаций; дополнительно перед каждой историей оставлен экран знакомства со спикером.

Общие служебные титулы «Исповедь» не дублируются в общей истории. Коллажи используют сетку с сохранением полного кадра: фотографии не налезают друг на друга и не обрезаются.

Финал без таймера и интерактива заканчивается фразой «Теперь ваш ход». Переходы сохраняют исходное движение в глубину без дополнительных вспышек и звука.

Исходные фотографии взяты из предоставленных презентаций и вашей папки `denis-it-path`. Глава Полины также сверена с [исходной HTML-версией](https://github.com/DenisSadykov/volunteer-school21).
